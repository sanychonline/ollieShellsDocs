# Ollie Shells Docs

Public product and support site for **Ollie Shells** / **Видреня Оллі**. The character is **Видреня Оллі**, catching falling shells in a three-lane arcade game.

## Site content

- Uses Ollie Shells app assets: character, shells, game background, icon, and logo.
- Uses Ollie's coral-and-tide palette consistently on `index.html`, `support.html`, `privacy.html`, and `terms.html`.
- Shows the approved Docs screenshots: launch art without a spinner, active gameplay with falling shells and no Game Over or banner, and English settings.
- Provides localized support in 17 interface languages.

## Deployment

The static public site is deployed from the repository `main` branch through GitHub Pages. The first live Pages deployment is completed and verified before any follow-up automation is introduced.
